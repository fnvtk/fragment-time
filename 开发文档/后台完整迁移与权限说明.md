# 碎片时间独立后台完整迁移与权限说明

## 访问与登录

- 后台：`https://fragment-time.quwanzhi.com/admin`
- 登录方式：读取生产数据库 `admin` 表，不再使用浏览器 Basic Auth。
- 原账号兼容：迁移脚本从 `AdminAccount` 导入不存在的账号；空 salt 账号按旧 MD5 校验，FastAdmin 账号按双 MD5 + salt 校验。
- 新建账号：使用 FastAdmin 双 MD5 + 随机 salt 保存，密码不会明文入库或返回前端。
- 会话：HttpOnly、Secure、SameSite=Lax 签名 Cookie，8 小时有效。

## 已迁移功能

| 模块 | 路径 | 能力 |
|---|---|---|
| 控制台 | `/admin` | 小程序真实用户、任务、领取、收益、提现统计 |

| 素材管理 | `/admin/attachments` | 本地上传、预览、访问、删除、附件记录入库 |
| 分类管理 | `/admin/categories` | 新建、编辑、排序、图片、状态、删除 |
| 通用配置 | `/admin/configs` | 分组配置、键名、类型、值、提示的增删改 |
| 操作日志 | `/admin/logs` | 登录及管理动作留痕、查询、删除 |

## 权限机制

1. 管理员通过 `auth_group_access` 关联一个或多个权限组。
2. 权限组的 `rules` 保存规则标识，`*` 表示全部权限。
3. 菜单按登录账号规则动态显示。
4. Middleware 同时限制页面和 API；无权限页面重定向控制台，无权限 API 返回 403。
5. 当前登录账号不可删除；仍有管理员的权限组不可删除。

## 数据库迁移

执行 `pnpm migrate:admin` 会幂等创建或补齐：`admin`、`auth_group`、`auth_group_access`、`auth_rule`、`admin_log`、`attachment`、`category`、`config`。不会修改 `WechatApp_*` 小程序业务数据。
